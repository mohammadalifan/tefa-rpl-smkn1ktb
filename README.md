# Aplikasi Team TEFA RPL

Repository bersama untuk pengembangan aplikasi oleh tim TEFA RPL.

## Memulai

1. Clone repository ini dari GitHub.
2. Diskusikan kebutuhan dan teknologi yang akan dipakai sebelum menambahkan fondasi aplikasi.
3. Buat branch untuk setiap pekerjaan, misalnya `fitur/login` atau `perbaikan/navigasi`.
4. Ajukan pull request agar perubahan dapat ditinjau sebelum digabungkan ke `main`.

## Aturan kerja singkat

- Simpan kredensial, token, dan konfigurasi pribadi di file `.env` lokal; jangan commit ke repository.
- Jelaskan tujuan dan cara menguji perubahan pada pull request.
- Catat keputusan penting dan petunjuk menjalankan aplikasi di README ini seiring perkembangan project.

## Status

Project baru dibuat. Kebutuhan, teknologi, dan struktur aplikasi akan ditentukan bersama tim.
